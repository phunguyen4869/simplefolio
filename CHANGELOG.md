# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added
- ViePilot brownfield artifacts (`.viepilot/`)
- Docker usage section in README (FEAT-001, Phase 1)
- Vietnamese README twin `README.vi.md` (ENH-001, Phase 3)
- Liquid glass redesign: dark/light themes, glass navbar, buttons, chips and cards, edge refraction on Chromium, press feedback
- Experience timeline (SmartGift Solution, BigIn)
- Projects bento grid
- English/Vietnamese language toggle (`src/data/translations.js`)
- Bottom tab bar navigation on phones
- Open Graph / Twitter card tags, bilingual description and keywords, `og-image.png`
- Static Vietnamese page `vi.html`, generated by `scripts/build-vi.mjs`, with its own canonical URL; the two pages link to each other with `hreflang`
- Vietnamese `aria-label` and `alt` texts
- Self-hosted Inter and Space Grotesk (Fontsource); no request to Google Fonts
- `npm run i18n`, `npm run format` and `npm run format:check`
- Résumé source `docs/resume.html`

### Changed
- Profile and project images converted to WebP
- README.md and README.vi.md rewritten for the new design
- Language toggle is a link between the two pages; it no longer swaps the copy with JavaScript (`translations.js` is now `translations.mjs`, read at build time)
- Reveal animations use `IntersectionObserver` and the Web Animations API; content stays visible without JavaScript
- Primary button uses a deeper gradient so its white text meets 4.5:1 contrast
- Liquid glass maps are redrawn after a resize settles, and only the newest 48 are cached
- Build empties `dist/` first and emits relative asset URLs (`--public-url ./`)
- Sass `@import` replaced by `@use`
- `og-image.png` converted to `og-image.jpg` (347 kB to 119 kB)
- Résumé replaced: current role, no phone number or home address
- `package.json` author, license (MIT), repository and homepage point to this fork

### Removed
- Bootstrap, Popper, Vanilla Tilt and Font Awesome
- GitHub fork/star buttons from the template footer
- ScrollReveal (loaded from unpkg)

## [1.0.1] - existing

Personalized fork of cobiwave/simplefolio (Phú Nguyễn). Docker dev server, Parcel 2, Bootstrap 5. History before this file lived in git only.
