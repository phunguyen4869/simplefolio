# Contributing

Personal portfolio fork. External contributions are not expected.

If you change this repo:

- Content: `src/index.html`, `src/assets/`
- Styles: `src/sass/**`
- Run: `npm start` (port 1234) or `docker compose up --build` (port 4869)
- Do not commit `node_modules/`, `dist/`, or `.parcel-cache/`
- Keep the MIT copyright notice in `LICENSE.md`
